## 闲话

拼尽全力无法战胜 milmon 最短解。

介绍一种不用主席树/树分块/莫队，用斜二倍增 + 逐块处理做到线性空间的实现。

由于我不会记号，下文 $[x,y]$ 表示 $x\rightarrow y$ 的祖先后代链，$[x,y)$ 表示 $[x,y]$ 删去 $y$。

## $o_x=o_y=0$

即需要求出 $f(x,y)$。

固定根 $R$，有以下基本观察：

- 若子树 $x$ 最大深度大于子树 $y$ 最大深度，则子树 $x$ 大于子树 $y$。数学归纳法易证。

- 子树信息合并等价于儿子信息合并。由上一条观察先比较儿子，若儿子相同则子树一定相同。

还需考虑反子树。注意到取直径中点较大端为 $R$ 时，任意反子树不小于除整棵树外的任意子树。这能减少讨论和代码难度。

对所有子树进行标号，即求 $rk$ 使得 $rk_x<rk_y$ 当且仅当子树 $x$ 小于子树 $y$。按最大深度分层，对于每一层用 `std::stable_sort` 按儿子集合排序，可以保证时间复杂度 $O(n\log n)$。

考虑求 $f(x,y)$，那么 $\text{path}(x,y)$ 中的子树变为反子树。

- $y\in[x,R]$：$y$ 对应反子树不小于所有子树，$f(x,y)=de_x-de_y+1$。

- $y\notin[x,R]$：在 $rk$ 的基础上 $[x,R]$ 中的反子树均大于 $y$ 子树，要加上原先不大于 $y$ 子树的数量。注意到是一段深度后缀，倍增计算。

时间复杂度 $O((n+q)\log n)$，期望得分 $36$ 分。

## $o_x=0,o_y=1$

为减少细节，将 $Y$ 容斥为到根链 $[Y,R]$。

基于求 $f$ 时的分类讨论，设 $\text{lca}(x,y)=g$：

- $y\in[Y,g)$：注意到是一段深度前缀，倍增即可。
- $y\in[g,R]$：注意到是一段深度后缀，可 $O(1)$ 计算答案。

结合前文，时间复杂度 $O((n+q\log n)\log n)$，期望得分 $48$ 分。

## $o_x=1,o_y=0$

为减少细节，将 $X$ 容斥为到根链 $[X,R]$。

基于求 $f$ 时的分类讨论：

- 若 $y$ 为 $X$ 祖先，可 $O(1)$ 计算 $x\in[X,y]$ 部分答案并令 $X\gets fa_y$。倍增求出 $[X,R]$ 中最深的 $rk_{x'}>rk_y$。

- $x\in[X,x')$：原倍增结果为 $x'$，可 $O(1)$ 计算答案。

- $x\in[x',R]$：原倍增结果为 $x$，可 $O(1)$ 计算答案。

结合前文，时间复杂度 $O((n+q\log n)\log n)$，期望得分 $60$ 分。

## $o_x=o_y=1$

设 $g=\text{lca}(X,Y)$，下面讨论 $x\in[X,g),y\in[Y,g)$ 的部分。其余部分 $x,y$ 为祖先后代关系，可 $O(\log n)$ 计算答案。

仔细观察求 $f$ 的过程，得到如下结论：对于 $[X,g)=p_1,\dots,p_m$，记 $a_i=f(p_i,y)$，则 $\{a_m\}$ 形如 $w,w-1,w-2,\dots,w',w',\dots,w'$。

那么先倍增将 $\forall x,f(x,y)\le r$ 和 $\forall x,f(x,y)>r$ 两类排除，这部分答案容易计算。

对于剩下的 $y$，根据观察的链形态有 $|\{x|f(x,y)\le r\}|=|[X,g)|+r-f(X,y)=|[X,g)|+r-(\sum[rk_i>rk_y]+1+\sum_{x\in[X,g)}[rk_x\le rk_y])$。

预处理树上前缀和，问题转化为给定两条路径 $A,B$ 求 $\sum[rk_{x\in A}\le rk_{y\in B}]$。其中 $A$ 是到根链，将 $B$ 挂在 $A$ 处离线处理。

将所有值排序后每 $L$ 个分一块，贡献分为相同块和不同块。逐块处理，对于不同块预处理两个树上前缀和即可。

对于相同块，在 dfs 序二维平面上考虑问题。根据 $O(L^2)$ 个贡献点对将平面划分为 $O(L^2)$ 个等价类，二维前缀和即可，定位等价类也是简单的。

这部分时间复杂度 $O(\frac{n}{L}(n+q+L^2))$，取 $L=O(\sqrt n)$ 得 $O((n+q)\sqrt n)$。

结合前文，总时间复杂度 $O((n+q\log n)\log n+(n+q)\sqrt n)$，期望得分 $100$ 分。

每块搜一遍常数超大，改成遍历 dfs 序能快好多。

#define TIME chrono::duration_cast<chrono::milliseconds>(chrono::high_resolution_clock::now().time_since_epoch()).count()

using namespace std;
typedef vector<int> arr;typedef pair<int,int> pii;typedef long long ll;
constexpr int N=1e5+5;
int csi,n;arr g[N];
int fa[N],de[N],sz[N],ht[N],lt[N];
int dl[N],dr[N],dfa[N],Tim;
void dfsI(int u){
    dfa[dl[u]=Tim=fa[u]?Tim+1:1]=u,de[u]=de[fa[u]]+1,sz[u]=1,ht[u]=1;
    int t=de[u]+de[lt[lt[u]]]==de[lt[u]]*2?lt[lt[u]]:u;
    for(auto v:g[u])if(v!=fa[u])fa[v]=u,lt[v]=t,
    dfsI(v),sz[u]+=sz[v],ht[u]=max(ht[u],ht[v]+1);
    dr[u]=Tim;
}
int rt;
void Init(){
    fa[1]=0,dfsI(1);int pp=1;rep(i,2,n)if(de[pp]<de[i])pp=i;
    fa[pp]=0,dfsI(pp);int qq=1;rep(i,2,n)if(de[qq]<de[i])qq=i;

}
int lca(int x,int y){
    if(de[x]>de[y])swap(x,y);while(de[x]<de[y])y=de[x]<=de[lt[y]]?lt[y]:fa[y];
    while(x!=y)lt[x]==lt[y]?(x=fa[x],y=fa[y]):(x=lt[x],y=lt[y]);return x;
}

}
void calrk(){

    idx=1;rep(i,2,n)if(SZ(buc[i])){
        for(auto u:buc[i]){for(auto v:g[u])if(v!=fa[u])sns[u].pb(rk[v]);
        sort(sns[u].begin(),sns[u].end(),greater<int>());}

}

    int xx=x;while(xx&&rk[xx]<=rk[y])xx=lt[xx]&&rk[lt[xx]]<=rk[y]?lt[xx]:fa[xx];
    return res+=de[x]-de[xx];
}
int Q00(int x,int y,int w){return F(x,y)<=w;}
int S01(int x,int y,int g,int w){

}

int S10(int x,int y,int w){

}

void Q11(int x,int y,int w,int qid){
    int g=lca(x,y);ans[qid]-=F(g,g)<=w;
    if(x!=g&&y!=g)S11(x,y,g,w,qid),S11(y,x,g,w,qid);

void work(){
    rep(i,1,idx)buc[i]={};rep(i,1,n)buc[rk[i]].pb(i);

        for(auto it:Q)ans[it.to]-=pc[0][it.x]*1ll*(pc[1][it.y]-pc[1][it.Y]);

        for(auto it:Q)if(pc[1][it.y]>pc[1][it.Y]){int xx=P[0][dl[it.x]];ans[it.to]+=S[I(xx,P[1][dl[it.y]])]-S[I(xx,P[1][dl[it.Y]])];}
    }
}

}
