HOW TO PLAY

一句一句，接下去。

  1. 找到熟悉的歌

    搜索歌名或歌手，也可以粘贴网易云歌曲、公开歌单的完整链接。

  2. 完整写出下一句

    网页给出上句，你接出紧接着的一整句。成功后继续向后接，直到歌的最后一句。

  3. 字词完整，才算接对

    忽略标点、空格、全半角和英文大小写；其余文字须与原文一致。少字、多字、错字、跳句都不通过。分句以网易云原文歌词为准。

  4. 卡住了，也可以慢慢想

    答错可以重试，连击清零。查看答案后可跳过这一句，跳过不计接对。曲库与接龙进度保存在当前浏览器。
