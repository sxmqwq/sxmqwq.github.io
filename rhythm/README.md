# rhythm · 网易云歌词接龙

入口：https://sxmqwq.github.io/rhythm/

搜索歌名、歌手，或粘贴网易云歌曲/公开歌单完整链接。读取的是网易云原文歌词，翻译不参与接龙。歌曲第一次加入后，歌词快照和进度保存在当前浏览器。无需登录，不提供音频播放。

## 接龙规则

- 从头开始时展示首句，玩家完整输入第二句；接对后继续填写下一句，直到末句。
- 支持从随机位置开始。
- 仅整句规范化后相等才通过。忽略 Unicode 标点、空白、全半角及英文大小写；其余字词均须一致。繁简、同音字、罗马音不自动互换。
- 答错留在原句，允许重试，连击清零；查看答案后只能明确跳过，不计为接对。
- 刷新页面后恢复未结束的接龙；每首歌的进度独立保存。
- 分句依照网易云原文。清理作词、作曲等署名，保留副歌重复及所有实际演唱句。

## 本地检查与发布

无构建依赖，Node.js 24：

```sh
node --test rhythm/tests/*.test.mjs
node scripts/build-rhythm.mjs
```

`rhythm/` 是编辑源，`docs/rhythm/` 是发布副本。`scripts/build-rhythm.mjs` 仅复制运行文件，不修改博客其他页面。请修改源目录后重新生成副本。

- `rhythm.yml` 在源文件推送后运行测试并发布整个 `docs/`。
- `Gmeek.yml` 在生成博客后重新复制本页面，防止后续博客发布遗漏小游戏。
- 两条工作流使用同一 Pages 部署并发组。

## 读取服务

GitHub Pages 不运行服务器，网易云原接口未提供浏览器跨域响应，因此通过两个公开只读适配服务读取网易云数据：

- injahow Meting：歌曲、歌单信息及原文 LRC。
- GD音乐台：网易云歌曲搜索及备用原文 LRC。

服务地址集中在 `config.mjs`。不携带用户 Cookie、登录凭据，不请求付费音频或音频下载接口。歌词请求带超时和备用来源；服务不可用时给出可重试错误，已保存歌词仍能继续使用。外部服务的可用性及覆盖范围会影响新歌曲读取。

页面歌词通过文本节点展示。接口返回值、歌词、歌曲标题均不作为 HTML 执行。浏览器存储使用独立键 `rhythm:netease:v1`，不会覆盖博客设置。
